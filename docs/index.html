One modular, zoomable, click-to-drill architecture diagram per model, with measured per-block ms and kernel breakdown overlaid from real trace data.

about

V2 diagrams are compiled from stable model semantics and execution plans; implementation bindings and profile measurements are independent overlays. New models use one canonical IR-first pipeline and the viewer consumes its compiled metadata.

Eager traces provide stack-backed semantic attribution and production traces provide timing, stream, overlap, and idle evidence. Measurements are accepted only against a matching execution fingerprint and cannot redefine the architecture.
